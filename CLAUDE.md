# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Repository Is

A personal Obsidian knowledge vault focused on spiritual development, meditation, and consciousness studies. This is a plain Markdown note-taking system — there are no build steps, tests, linters, or scripts.

## Version Control

The vault is git-tracked. Commits are infrequent and broad (e.g., "updated the whole vault"). The `.gitignore` excludes Obsidian workspace state, cache, and plugin config, while preserving plugin manifests and stylesheets.

## Content Structure

All substantive notes live under `Spiritual notes/`:

- **`Meditation/`** — The largest collection, organized by topic: `Consciousness/`, `Visualisation/`, `Artificial intelligence/`, `Rules and governance/`, `Links/`
- **`Daily Meditation Notes/`** — Dated personal journal entries
- **`Personal-Lexical-Grammer/`** — Language study, personal writing projects, and a Zettelkasten-style inbox/seeds/themes/notes hierarchy
- **`Deva-notes/`** — Esoteric studies on subtle forces and devas
- **`Deep-thoughts/`** — Stoic philosophy notes

Top-level files (`Patanjali-Yoga-sutras.md`, `Markdown-cheatsheet.md`) are standalone references.

## Obsidian Configuration

Stored in `.obsidian/`. Core plugins enabled include: graph view, backlinks, canvas, tags, templates, daily notes, word count, and bases. No community plugins are installed.

The `Spiritual notes/` subfolder has its own `.obsidian/` config — it can be opened as a separate nested vault.
